01 — CONVERSATIONAL AI

A voice agent built
for difficult conversations.

Outbound payment reminders at Remynt, with identity verification, interruption handling, hardship routing, and a path to a human.

  • Twilio
  • AssemblyAI
  • LLMs
  • ElevenLabs
Explore the engineering +

The challenge

Keep conversations responsive while enforcing verification and handling interruptions, uncertainty, and sensitive workflows.

My approach

Connected telephony, streaming speech recognition, LLM reasoning, and speech synthesis. Combined voice activity, transcript stability, and silence thresholds for endpointing; added barge-in and explicit human handoff.

A deliberate boundary

Backend checks return verification results so the conversation layer can act on a boolean outcome. Payment-link delivery and hardship routing follow defined paths.

02 — LLM SYSTEMS

Making AI answers
traceable.

Compliance review and natural-language analytics built around retrieved context, structured checks, and human review.

  • RAG
  • SQL
  • Evaluation
Explore the engineering +

Compliance review

Combined rule checks and LLM scoring with criticality-based routing. Versioned retrieval and citations support review; managers handle cases that need judgment.

Natural-language analytics

Reused trusted queries for high-confidence matches, adapted partial matches, and used retrieval-assisted SQL generation when needed. Query critique, access controls, and caching help make the workflow practical.

The principle

Use deterministic checks where precision matters and reserve model reasoning for ambiguity.
